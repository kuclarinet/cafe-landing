# cafe-landing

가상의 동네 카페 "모닝브루"를 위한 간단한 랜딩 페이지입니다. 별도 빌드 없이 정적 HTML/CSS만으로 만들어졌습니다.

## 구성

| 파일 | 설명 |
| --- | --- |
| `index.html` | 페이지 본문 (히어로, 대표 메뉴, 소개, 오시는 길, 푸터) |
| `style.css` | 스타일 (커피 톤 색상, 반응형 카드 레이아웃) |

## 사용법

`index.html`을 브라우저에서 열면 바로 확인할 수 있습니다.

## 참고

메뉴 가격, 주소, 전화번호는 모두 예시 값입니다.
